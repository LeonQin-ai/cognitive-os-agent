# 自动脱敏仅针对 SSH 密码（#115）

按用户要求，模型输入/输出、流式输出、日志、任务参数与工具详情、记忆写入的自动过滤
仅匹配已由用户提供、或从本地 SSH vault 取出的实际 SSH 密码。不再因通用
`password=`、Bearer、API key、token、高熵字符串或路径格式修改其他文本。

密码注册只在进程内保存匹配值，不持久化新的明文副本；已有 vault 加密/访问权限机制保留。
原始登录描述仍在排队和记录前按密码跨度替换为 `[LOCAL_SSH_PASSWORD]`，后续边界对
已知密码回显使用 `[REDACTED:ssh_password]`。JSON 转义后的同一密码也会被保护。
严格模式只检查已知 SSH 密码，不会因其他凭据文本阻止模型调用。

短于 4 字节的密码在原始描述中按确切跨度处理；在后续回显中需要密码标签上下文，
避免把源码里的普通数字、字母全部擦除。密码匹配按原始字节处理，不做内容改写。

流式过滤按已知密码长度保留尾部，处理跨块匹配；已遮盖的片段不会重新作为原文尾部输出。
1024 字节密码和 JSON 转义形式均在支持范围内。通用检测函数保留供显式诊断测试使用，
已经没有运行时自动过滤调用点。

新增原生用例覆盖日志、模型输入输出、记忆、通用凭据/路径原样保留、已知 SSH 密码回显、
JSON 转义、短密码上下文及 7 字节流块里的 1024 字节密码。
真实 HTTP/调度/模型协议用例读取包含 password/token/Bearer/路径的源码，验证模型观察、
最终回答、任务详情和会话历史逐字保留；实际本地 OpenSSH 密码认证用例继续执行。
