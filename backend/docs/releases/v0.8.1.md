## v0.8.1

### 修复

- 修复多 Agent Flow 的“继续执行”状态不刷新问题；任务与节点进度会自动更新，恢复失败时显示错误，完成后展示结果。
- 修复聊天图片上传后的预览和消息展示；支持已发送图片回看、放大，以及安全渲染模型返回的 Markdown 图片。
- 修复带英文缩写所有格的自然语言前缀导致 DSML 工具调用解析失败。
- 加强 todo-cli 项目验收：独立验证删除后的 ID 不复用，并校验生成的 PPTX 内容；不再依赖项目自测中的错误断言。
