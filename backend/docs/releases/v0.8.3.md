## v0.8.3

### 修复

- 模型上下文窗口读取模型目录中的 `context_window` 元数据；无元数据时默认 256K，并移除界面的手动“改窗口”按钮。相同端点有多条路由时，优先使用后来配置的路由元数据。
- 点击“新聊天”会创建独立且持久的会话；旧会话按任务日志的最新状态显示，重启后遗留的 RUNNING 状态显示为可恢复的中断，而非误报失败。
- Flow 节点完成后保留轮次、模型调用、token、工具和步骤快照，便于追查多 Agent 执行结果。
- 修正源码分页读取的覆盖记录和文件版本失效逻辑，减少重复读取；循环中止时整理实际执行结果。
- Git 工具在工作区不是仓库时给出明确诊断；构建时始终重新生成嵌入式网页，避免安装包带旧界面。

### 验证

- Windows 原生 C 单元测试：3728 passed，0 failed。
- Playwright 回归覆盖新聊天重复点击、创建失败、旧任务状态恢复、图片上传和预览。
- Linux、Windows、macOS 与 AddressSanitizer CI 验证。
