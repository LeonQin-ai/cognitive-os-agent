## Cognitive OS Agent 2.0.0

Stable main-branch release before the workspace and terminal-client integration.

- Keep IM messages visible during refresh, isolate stale group responses, prevent duplicate sends and preserve drafts after failures.
- Aggregate model calls, failures, timing and token usage across all roles in a discussion.
- Finish sufficient observations without equivalent repeated probes; preserve explicitly requested multiple samples.
- Clean PowerShell progress output, emit UTF-8 and guard MSVC-specific WinHTTP linker pragmas.

Validated with configured real-model API runs, deterministic regressions and the five-platform main CI. Workspace selection and the fullscreen terminal client remain development features at this release tag and are integrated into main afterwards.

Apache-2.0. Existing state and model configuration remain compatible.
