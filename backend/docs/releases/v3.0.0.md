## Cognitive OS Agent 3.0.0

Major release integrating workspace execution, the terminal client, memory
inspection and task-delivery reliability improvements on main.

- Workspace selection and task execution in the selected project directory.
- Terminal client and multi-Agent/Flow execution improvements.
- User-generated read-only memory summaries, full copying and restart recovery.
- Rolling compaction carries previous constraints, decisions and outstanding work.
- Structured completion review and legacy protocol recovery; preserve real tool
  evidence, failed diagnostics and complete delivered output.
- Expandable Trace details and chat timestamps.
- Windows desktop startup animation with a sea-breeze palette, accessible loading
  status and reduced-motion support. This is a palette-based theme, not the
  reference wallpaper or an animated character asset.

### Validation and scope

Release requires the main CI to pass on Linux, ASAN, Windows and both macOS
architectures, followed by successful platform packaging. Configured real API
checks covered memory summaries, repeated compaction retention, UNKNOWN
abstention and paginated source-to-HTML delivery. Failed experiments and token
costs remain documented; passing targeted checks is not a guarantee that every
provider or long-running task succeeds. Issue #232 retains its unresolved
deployment-specific reports until their acceptance is confirmed.

Apache-2.0. Back up existing state before upgrading; retain the existing state
directory and provider configuration when installing the new version.
