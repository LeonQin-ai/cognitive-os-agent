## v0.8.0

### 新功能与修复

- 扩展聊天附件：图片、Word、PPT、PDF 和视频均可上传并传入模型；支持页面渲染、扫描 PDF 图像和带时间标签的视频画面采样。
- 修复上传后立即发送、切换会话导致附件错配的问题；附件使用独立 ID，修复同名文件覆盖、删除后残留及重启恢复问题。
- 修复聊天执行中不自动滚动的问题；跟随最新思考过程，同时保留用户手动查看历史记录的位置。
- 优化 Windows 标题栏：清晰窗口图标、悬停反馈、高 DPI 适配及最小化／最大化／还原操作；修复最大化后两侧黑边。
- Windows 安装和升级时始终允许选择安装路径，安装确认页展示最终目录。
- 改进 HTTP 并发、请求边界校验、任务历史内存上限和关闭等待；修复 Windows 子进程继承套接字导致连接重置的问题。

### 安装包

- Windows：`cognitive-os-agent-setup.exe`
- Linux：`cognitive-os-agent-linux-x64.tar.gz`
- macOS Apple Silicon：`cognitive-os-agent-macos-arm64.zip`
- macOS Intel：`cognitive-os-agent-macos-x64.zip`

### 附件处理依赖与范围

附件解析需要 Python 和可选格式依赖：下载源码中的
[`requirements-attachments.txt`](https://github.com/LeonQin-ai/cognitive-os-agent/blob/v0.8.0/backend/tools/requirements-attachments.txt)，运行 `python -m pip install -r requirements-attachments.txt`。
旧版 DOC/PPT 及完整 Office 页面渲染需要已安装的 Word/PowerPoint 或 LibreOffice。
图片、扫描 PDF 和视频画面理解需要支持视觉输入的模型；视频暂不包含音轨转写。
单文件上限 64 MiB，每条消息最多四个附件。
详细格式与依赖见[附件说明](https://github.com/LeonQin-ai/cognitive-os-agent/blob/v0.8.0/backend/docs/attachment-formats.md)。
