## Cognitive OS Agent 1.0.0

本次正式版本汇集 v0.8.3 以来的任务执行、历史保存、可观测性与界面改进，提供 Windows、Linux 和 macOS 安装包。

### 任务执行与完成判断

- 原生协议依据工具调用与结构化 `complete_task` 推进，兼容协议增加交付复核，避免把进度说明当成完成。
- 可选源码探查发现路径不存在时，支持引用后续准确父目录的成功列举证据完成收尾；既有文件未读、失败写入与无关证据仍不能绕过校验。
- 改进单次响应复读、输出限额、失败恢复和模型路由诊断；无可用内容的隐藏思考不会触发盲目扩额。
- 观察日志按模型输入预算保留，减少固定小窗口造成的反复补读。

### 完整回答与 Trace

- 成功、失败及阶段性结论完整写入任务日志，不再截取前 4095 字节。
- 移除历史会话 4 MiB、任务日志 32 MiB 的读取障碍；日志逐条读取，原文保存与模型上下文摘要分开处理。
- 修复旧记录 UTF-8 截断兼容问题，长回答在切换会话与重启后仍可完整读取。
- Trace 可展开查看实际命令、返回结果、状态及毫秒耗时；预览长度受控，完整任务记录独立保留。

### 配置与界面

- NVIDIA NIM 合并为统一模型入口，保留模型选择与填写能力。
- 技能与插件的高级区域采用独立折叠分区及响应式卡片，目录刷新保留展开选择。
- 修复 SkillHub 空搜索报错，补充安装、面板切换、发布表单与窄屏布局回归。
- 同步 CLI、网页、Windows 安装器和 macOS 应用版本为 1.0.0。

### 验证与已知问题

- 发布前业务代码的本地完整单元测试：**4492 passed / 0 failed**。
- 对应 CI [39880065243](https://github.com/LeonQin-ai/cognitive-os-agent/actions/runs/39880065243) 在 Windows、Linux GCC/ASAN、macOS ARM64/Intel 全部通过。
- 已配置真实 API 通过 Agent 完成可选源码缺失的针对性回归：9 次请求、6 次工具执行、61526 reported tokens；完整证据与测试脚本检查错误的说明见 [历史回归证据](https://github.com/LeonQin-ai/cognitive-os-agent/blob/v1.0.0/backend/docs/task68-completion-regression.md)。
- 大于 64 KiB 的成功及失败结论、4 MiB 以上历史回答、32 MiB 以上日志均有完整保存与重启读取回归。
- [#204](https://github.com/LeonQin-ai/cognitive-os-agent/issues/204) 简单实时查询重复调用和 [#188](https://github.com/LeonQin-ai/cognitive-os-agent/issues/188) 间歇性 Windows SSH 超时仍在跟踪。本版不宣称消除所有重复消耗，也不承诺突破模型服务自身的上下文或输出上限。

### 下载与升级

- Windows x64：`cognitive-os-agent-setup.exe`，安装向导支持选择目录。
- Linux x64：`cognitive-os-agent-linux-x64.tar.gz`。
- macOS Apple Silicon：`cognitive-os-agent-macos-arm64.zip`。
- macOS Intel：`cognitive-os-agent-macos-x64.zip`。

升级前结束正在执行的任务并退出应用，再安装新版本；请保留原有 state 数据和模型配置。
