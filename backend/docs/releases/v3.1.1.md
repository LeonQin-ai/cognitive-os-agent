## Cognitive OS Agent 3.1.1

- Show the theme switcher directly in the desktop sidebar and keep appearance controls synchronized.
- Load complete persisted conversation history instead of silently limiting the view to 200 turns or task records.
- Reduce history response processing by selecting session records before serialization and retaining only the latest transition of each task.
- Show history loading, completion and retry states. Preserve existing content when loading fails.

### Validation

The fixes passed main CI and container smoke checks before release preparation. Regression coverage includes 250 persisted turns and task records, session isolation, restart recovery, desktop theme switching and chat image rendering.

Packages include Windows x64 installer, Linux x64 and ARM64 portable archives, and macOS x64/ARM64 ZIP and PKG installers. Updating the installed application is required to receive these changes; historical data is retained.
