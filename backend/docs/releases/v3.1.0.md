## Cognitive OS Agent 3.1.0

- Add a native Linux ARM64 portable package, built and smoke-tested on an ARM64 runner alongside Linux x64.
- Connect scoped persistent memory and Context MMU recall to Agent tasks and Flow. Include reproducible scale benchmarks and real API A/B measurements.
- Fix bulk artifact verification dropping shell outputs after the sixteenth file; add 50-file delivery regressions for native and legacy protocols.
- Fix corrected directory probes incorrectly blocking task completion, and clarify provider quota failures.
- Improve chat image previews, natural image proportions and real API browser regression coverage.
- Restore readable chat surfaces over wallpapers and theme switching in desktop appearance settings.
- Add custom local startup animations (GIF, WebP, MP4, WebM), and suppress native window resize borders.

### Downloads

Linux: `cognitive-os-agent-linux-arm64.tar.gz` (AArch64) or `cognitive-os-agent-linux-x64.tar.gz` (AMD64). These are native GNU/Linux builds; Alpine/musl systems require a compatible runtime or container.

Windows: x64 installer. macOS: ARM64 and x64 ZIP/PKG packages.

Memory A/B is a small fixed-task sample, not a general success-rate guarantee. See `backend/docs/MEMORY_SCALE_BASELINE.md` for measurements and limitations.
