# 完整浏览器/工具结果（#123）

原因：tool_execute原先只保留前8000字符；reasoning每条记录6144字节再执行首尾保留，中间正文不可找回。重新打开同一页面不能修复这类数据丢失。

修复：超过6000字节的工具结果完整保存到工作区 `.tool-results/<unique>.txt`；仅将文件路径、字节数、4000字节分页参数和短预览放入模型上下文。Agent按next_offset_bytes读到EOF。保存前只过滤已登记的SSH密码，普通源码password/token字段保持原文。保存失败返回失败状态，不能把被截断结果算作完整成功。

规划器提示区分导航/可访问性快照与正文；浏览器MCP支持时读取加载完成的document.body.innerText及相关frame，并按实际网站处理滚动加载或分页。完整网页/文档读取也受EOF完成检查约束。

验证：原生测试20000字节正文，中间标记、非SSH字段和SSH脱敏范围、通过绝对路径继续读取、结果文件写入失败。真实Runtime HTTP端到端使用本地浏览器MCP协议fixture，返回18000字节正文，Agent只调用一次browser_evaluate，再连续读取5页并核对中间/结尾，任务DONE。fixture验证传输/保存/分页链路，不代表所有网站或真实浏览器兼容性。

文件保留供任务后续检查。网站本身分页、iframe或懒加载仍须使用已安装浏览器MCP提供的相应操作；没有把页面预览当作全站内容。用户issue没有给具体网址，若个别站点仍失败，应根据实际工具错误补充站点用例。
